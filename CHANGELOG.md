# Changelog

## 1.2.2

- Updated the project for the Minecraft 26.2 / Paper 26.2 target.
- Standardized release versioning between Gradle, `plugin.yml`, GitHub Releases, and the configuration version.
- Kept the distribution focused on the installable Paper plugin JAR.
- Hardened configuration and optimization behaviour to avoid unnecessary gameplay changes.

This release is intended for Paper 26.2 running on Java 25.
